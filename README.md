# Rude Magic 8 Ball

My first Python project.

This is a simple Magic 8 Ball program that gives random sarcastic and rude answers to the user's questions.

## Why I built this

I am currently learning Python from scratch and wanted to practice:

- Variables
- User input (`input()`)
- Conditional statements (`if`, `elif`, `else`)
- Random numbers (`random.randint`)
- String concatenation
- Basic program structure

Instead of following a tutorial step by step, I tried to build the project myself and solve the problems as they appeared.

## What the program does

1. Asks for the user's name.
2. Asks a question.
3. Chooses a random answer.
4. Displays a sarcastic response.

Example:

```text
Enter your name: Alex
Ask your question: Are there any good politicians?

Alex asks: Are there any good politicians?

Rude Magic 8 Ball says:
There are questions to be answered, and then there are stupid questions.
